## Guidelines

- **Capture from a real device or emulator, not a design mockup.**
- Prefer the default appearance theme (Sky Blue) unless a screenshot is specifically about themes.
- Keep a consistent device size and orientation (portrait) across the set.
- Crop out status-bar clutter where it adds no information.
- Keep the interface language consistent across the set unless the point is to show localization. If you add localized variants, name them `library.en.png`, `library.zh-CN.png`, `library.zh-TW.png`.
- Keep each file reasonably small (a few hundred KB); PNG is fine, and downscaling to ~1080px wide is usually enough.
- **Check that no personal data is visible** — no real reading history, no file paths, no names you would not want public.
